# PokerNet Implementation Plan (plan 2 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Changed during Task 1:** WebSocket was replaced by newline-delimited JSON over TLS-PSK/TCP. `NWProtocolWebSocket` clients only complete the upgrade with a `.url` endpoint, while Bonjour and AWDL deliver `.service` endpoints. TLS-PSK works unchanged. The constraints below already reflect this.

**Goal:** Target `PokerNet` in the package `PokerChipCase`: host server and client that play `PokerCore` games encrypted over the local network (Wi-Fi or peer-to-peer), with Bonjour discovery, reconnect via token, and a restorable host state.

**Architecture:** `MessageChannel` wraps an `NWConnection` (TCP + TLS-PSK, one JSON message per line) as an `AsyncThrowingStream`. `TableHost` (actor) owns the `HostSnapshot` (game + token table), accepts connections, turns `hello`/`command` into `Game.apply` and sends `ack` and `state`. `TableClient` (actor) connects, sends commands with `stateVersion`, waits for the `ack` and reconnects by itself after drops. The host device also uses `TableClient`, over loopback with the host token.

**Tech Stack:** Swift 6, `Network.framework` (`NWListener`, `NWConnection`, `NWBrowser`, `NWProtocolTLS`), `CryptoKit` (HKDF), Swift Testing. No external dependencies.

**Spec:** `docs/superpowers/specs/2026-11-11-pokerchipcase-design.md` · Protocol: `docs/PROTOCOL.md`

**Previous:** plan 1 `PokerCore` (merged). **Next:** plan 3 app.

## Global Constraints

- Platforms stay `.iOS(.v17)`, `.macOS(.v14)`; tests run with `swift test` on macOS without an iPhone
- No external dependencies
- Transport exactly as in `docs/PROTOCOL.md`: TLS 1.2 (min and max), cipher suite `TLS_PSK_WITH_AES_128_GCM_SHA256`, PSK = HKDF-SHA256(ikm: code UTF-8, salt: `pokerchipcase-v1`, info: `pokerchipcase-psk`, 32 bytes), PSK identity `pokerchipcase`, one UTF-8 JSON message per line terminated by `\n`, Bonjour type `Wire.serviceType`
- `includePeerToPeer = true`, `allowLocalEndpointReuse = true`, TCP keepalive on (`keepaliveIdle = 2`)
- At most 1 MiB per line; longer lines end the connection (`ChannelError.messageTooLarge`)
- Tests connect over loopback `NWEndpoint.hostPort(host: "127.0.0.1", port:)`; only Task 5 uses Bonjour
- Every async test waits at most 5 s for an event (helper `EventRecorder`), suite trait `.timeLimit(.minutes(1))`
- **Stop condition:** if TLS-PSK cannot be established with the installed SDK (Task 1), do not switch to another encryption; stop and ask. That is a security decision.

## Review Focus

1. **Host restart from a saved snapshot:** clients reconnect with their token and keep their seat → `clientReconnectsAfterHostRestart` (Task 4).
2. **The same token connects twice** (old connection not yet detected as dead): the new one wins, the old one is closed → `secondConnectionWithSameTokenReplacesFirst` (Task 2).
3. **Wrong table code:** immediately `failed(.wrongCode)`, no endless retrying → `wrongCodeFailsWithoutRetry` (Task 4).
4. **Broken message:** the host answers `malformed`; the connection and all others stay up → `malformedMessageGetsErrorAndConnectionStays` (Task 3).
5. **Sending without a connection:** throws `ClientError.notConnected` immediately, does not hang → `sendWhileDisconnectedThrows` (Task 4).

- [ ] **Step 3: Implement**

`HostSnapshot.newTable`: host ID and host token are each `UUID().uuidString`; `Game(hostID:hostName:config:)`.
`TableHost`: `NWListener(using: PSK.parameters(code:), on: port)`; `start` waits for `.ready` and returns the port, `.failed` → throws. Per connection a `UUID`, a `MessageChannel` and a `Task` that reads its `events` and calls `handle(_:from:)` on the actor. State: `channels: [UUID: MessageChannel]`, `bound: [UUID: PlayerID]`.
`hello` rules, in this order:
1. `protocolVersion != Wire.version` → `.error("versionMismatch")`, close the channel
2. token known → bind to that player; close and remove any other connection of the same player
3. otherwise a new player: `PlayerID = UUID().uuidString`, `game.apply(.join(player:name:), by: hostID, at: Date())`; `.tableFull` → `"tableFull"`, `.invalidPhase` → `"gameInProgress"` (each as `.error`, close the channel); on success store the new token, `onChange(snapshot)`
4. `.welcome(Welcome(player:token:))` to this connection, then `.state` to **all** bound connections

Server messages each get a new `UUID` as envelope `id`. Channel end → remove the connection (the seat stays). `stop()` ends the listener and all channels.

- [ ] **Step 3: Implement**

`connect`: `MessageChannel(to:code:)`; on `.ready` the client sends `hello(protocolVersion: Wire.version, name:, token:)`. Server messages:
- `welcome` → take the token, connected = true, `.welcome`
- `state` → `lastState`, `.state`
- `ack` → resume the waiting continuation for `ack.id`
- `error` with code `versionMismatch` / `tableFull` / `gameInProgress` → `.failed(...)`, no retry; ignore other codes

Channel end: if it ends with `ChannelError.handshakeFailed` → `.failed(.wrongCode)`, done. Otherwise `.connectionLost` (only if connected before), resume all waiting `send` calls with `ClientError.connectionLost`, reconnect after `retryDelay`, until `disconnect()`.
`send`: not connected → `ClientError.notConnected`; otherwise `id = UUID()`, store the continuation under `id`, send `.command(CommandRequest(command:, stateVersion: lastState?.version ?? 0))`, wait for the `ack` and return its `result`.
