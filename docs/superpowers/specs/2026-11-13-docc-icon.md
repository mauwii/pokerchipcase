# DocC docs and app icon

A DocC site for contributors on GitHub Pages, with API reference and the wire protocol, and an app icon with light, dark and tinted appearances. One PR.

## DocC

### Catalogs

One catalog per library, each with a module overview page: what the module does, what it depends on, and its main types grouped as topics.

- `Sources/PokerCore/PokerCore.docc/PokerCore.md`
- `Sources/PokerNet/PokerNet.docc/PokerNet.md`
- `Sources/PokerSession/PokerSession.docc/PokerSession.md`

No separate architecture article: the three overviews and their dependency lines describe it.

### Protocol

`docs/PROTOCOL.md` moves to `Sources/PokerNet/PokerNet.docc/Protocol.md` with `git mv`, so its history stays. Type names in it become ``` ``Symbol`` ``` links where the symbol exists. The PokerNet overview lists it under its topics.

Update every reference to the old path:

- `AGENTS.md`: the layout entry and the rule "Update it in the same PR as any wire-format change".
- `README.md`, `CONTRIBUTING.md`.
- `Sources/PokerNet/Security.swift`, `Sources/PokerCore/Wire.swift`.

Specs and plans under `docs/superpowers/` keep the old path; they record history.

### Doc comments

Every public top-level type in the three libraries gets a `///` summary. Members get one only where the name does not say enough. The rest of the public API stays as it is and becomes one GitHub issue labeled `deferred` and `core`.

### Build and deploy

A new workflow `.github/workflows/docs.yml`, `permissions: contents: read` at the top:

- Job `build` on `macos-latest`, on `pull_request` and on `push` to `main`:
  1. `actions/checkout`, pinned like in `ci.yml`, `persist-credentials: false`.
  2. `xcodebuild docbuild -scheme PokerChipCase-Package -destination 'generic/platform=macOS' -derivedDataPath .build/docs`.
  3. `xcrun docc merge` of the three `.doccarchive` bundles into one archive with a synthesized landing page named `PokerChipCase`.
  4. `xcrun docc process-archive transform-for-static-hosting <archive> --output-path .build/site --hosting-base-path pokerchipcase`.
  5. On `push` only: `actions/upload-pages-artifact` with `.build/site`.
- Job `deploy`, on `push` only, `needs: build`, on `ubuntu-latest`: `environment: github-pages` (deployment branch `main` only), `permissions: pages: write, id-token: write`, and `actions/deploy-pages`.

All actions are GitHub-owned and pinned by commit SHA. No new package dependency: `xcodebuild docbuild` works without `swift-docc-plugin`. No secrets.

Maintainer setup: Settings, Pages, source "GitHub Actions".

`README.md` links the site: `https://mauwii.github.io/pokerchipcase/documentation/`.

## App icon

### Design

A red poker chip on green felt with a black spade in the middle. In a 100 × 100 viewBox:

| Part | Shape |
|---|---|
| Background (light) | full square, radial gradient `#2f8a4e` (center, at 50 % / 40 %) to `#1d5e33`, radius 70 % |
| Chip body | circle r 36, `#c0392b`, edge `#000` at 20 % opacity, width 1 |
| Edge inserts | circle r 31, no fill, stroke `#fff` width 9, `stroke-dasharray` 12.17 12.17 (8 inserts) |
| Center | circle r 22, `#c0392b`, stroke `#fff` width 1.6, `stroke-dasharray` 2 2 |
| Spade | path `M50 36 C44 43 38 46 38 52 C38 57 43 59 47 56 C46 60 45 62 43 64 L57 64 C55 62 54 60 53 56 C57 59 62 57 62 52 C62 46 56 43 50 36 Z`, fill `#111`, stroke `#fff` width 1.8, round joins |

The square is not rounded; iOS applies the mask.

Appearances:

- **Light**: as above, no alpha channel.
- **Dark**: the same chip on a transparent background; iOS draws its dark backdrop behind it.
- **Tinted**: the same layout in grayscale on a transparent background. The chip body and center are `#8a8a8a` and the spade fill is `#222`; white stays white. iOS tints it.

### Files

- `App/Icon/icon.svg`, `icon-dark.svg`, `icon-tinted.svg`: the sources. Each starts with a comment that names its render command, `rsvg-convert -w 1024 -h 1024 <svg> -o <png>` (`brew install librsvg`). The light PNG also needs its alpha channel removed. Rendering is manual; CI does not render.
- `App/Sources/Assets.xcassets/Contents.json` and `AppIcon.appiconset/`: three 1024 × 1024 PNGs, and a `Contents.json` with one single-size `universal`, `platform: ios` entry per appearance (none, `luminosity: dark`, `luminosity: tinted`).
- `App/project.yml`: `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon` in the target's base settings. The catalog is under `Sources`, so xcodegen picks it up.
