# PokerChipCase Protocol (version 1)

This document describes everything a compatible client (for example an Android app) needs to join a PokerChipCase table. The types in `Sources/PokerCore/` and the golden tests in `Tests/PokerCoreTests/WireTests.swift` are authoritative.

## Transport

| | |
|---|---|
| Discovery | Bonjour/mDNS, service type `_pokerchipcase._tcp`, instance name = table name |
| Connection | TCP with TLS; inside, one message per line: UTF-8 JSON terminated by `\n` (0x0A), at most 1 MiB per line |
| TLS | TLS 1.2, pre-shared key, cipher suite `TLS_PSK_WITH_AES_128_GCM_SHA256` |
| PSK | HKDF-SHA256: input = 4-digit table code (UTF-8), salt = `pokerchipcase-v1` (UTF-8), info = `pokerchipcase-psk` (UTF-8), 32-byte output |
| PSK identity | `pokerchipcase` (UTF-8) |
| PSK test vector | code `4711` → `67a659eb4579867f3873c0e9311b75f65b3d6d0b7c0c7cdc7687d0fb78f423f2` (hex) |
| Peer-to-peer | iOS additionally uses AWDL (`includePeerToPeer`); other platforms use the shared Wi-Fi |

A wrong table code makes the TLS handshake fail. JSON is encoded compactly and therefore never contains a raw newline. A peer that receives a longer line drops the connection.

## Envelope

Every message, in both directions:

```json
{"id":"<UUID>","payload":<payload>,"type":"<type>","v":1}
```

- `v` – protocol version. Messages with a different version are rejected.
- `id` – UUID with hyphens, generated by the sender. iOS writes upper case; receivers compare case-insensitively.
- `type` – determines the shape of `payload`.
- Dates are milliseconds since 1970-01-01 UTC, as a number.
- Durations (`duration`, `pausedRemaining`) are seconds, as a number.

### Encoding of enums with associated values

`Command`, `Action` and `AckResult` are encoded as an object with exactly one key – the case name. Its value is an object with the labeled fields, or `{}` for cases without values:

```json
{"act":{"action":{"raiseTo":{"amount":60}},"player":"B"}}
{"fold":{}}
```

Enums without values (`Phase`, `Street`, `Rejection`) are plain strings.

## Client → Host

### `hello` – join or reconnect

```json
{"id":"00000000-0000-0000-0000-000000000001","payload":{"name":"Anna","protocolVersion":1},"type":"hello","v":1}
```

`payload.token` (optional) is the token from an earlier `welcome`; with it the client takes its seat back after a disconnect. An unknown token counts as a new join. If a token connects a second time, the host closes the older connection.

### `command` – every game command

```json
{"id":"00000000-0000-0000-0000-000000000001","payload":{"command":{"act":{"action":{"raiseTo":{"amount":60}},"player":"B"}},"stateVersion":7},"type":"command","v":1}
```

`stateVersion` is `version` from the last `state` received. If it no longer matches the host's, the command is rejected with `staleState`. This discards double taps that arrive after the state has changed.

| Command | Fields | Who may send it |
|---|---|---|
| `join` | `player`, `name` | host only (the host issues it itself after `hello`) |
| `removePlayer` | `player` | host, not for itself |
| `arrangeSeats` | `order` (all player IDs) | host, lobby only |
| `startTournament` | `button` | host, at least 2 players |
| `act` | `player`, `action` | the player when it is their turn; the host additionally `fold`/`check` for others |
| `resolveShowdown` | `winners`: one list of player IDs per pot, in the same order as `state.pots`; each list non-empty, no duplicates, only IDs from `eligible` | dealer of the hand or host |
| `startNextHand` | – | dealer of the hand or host |
| `pauseClock`, `resumeClock` | – | host |
| `undo` | – | host |

Actions (`action`): `fold`, `check`, `call`, `raiseTo` with `amount` (total bet in this betting round; a bet if nobody has bet yet), `allIn`.

### Deriving legal actions

`state` does not contain a list of legal actions. For the player to act (`seats[toActIndex]`, called `s` below):

- `toCall = max(0, currentBet − s.roundBet)`
- **Check** is allowed if `toCall == 0`; otherwise **call** for `min(toCall, s.stack)` chips.
- `allInTo = s.roundBet + s.stack`
- **Raise** is allowed if `s.mayRaise` and `allInTo > currentBet`. Then `raiseTo.amount` lies between `min(currentBet + lastRaiseSize, allInTo)` and `allInTo`.
- `raiseTo` with `amount == allInTo` and `allIn` are always equivalent, even below the minimum raise. An all-in that goes above `currentBet` still requires `mayRaise`.
- **Fold** is always allowed.

## Host → Client

### `welcome` – reply to `hello`

```json
{"id":"…","payload":{"player":"B","token":"…"},"type":"welcome","v":1}
```

Keep the token secret and store it for reconnects.

### `ack` – reply to every `command`

```json
{"id":"00000000-0000-0000-0000-000000000001","payload":{"id":"00000000-0000-0000-0000-000000000001","result":{"rejected":{"reason":"notYourTurn"}}},"type":"ack","v":1}
```

`payload.id` is the `id` of the `command` being answered. `hello` gets no `ack`; it gets `welcome` + `state`, or `error`. `result` is `{"ok":{}}` or `{"rejected":{"reason":"<Rejection>"}}`.

Reasons: `notHost`, `notDealer`, `notYourTurn`, `invalidPhase`, `illegalAction`, `invalidAmount`, `unknownPlayer`, `duplicatePlayer`, `tableFull`, `tooFewPlayers`, `invalidShowdown`, `nothingToUndo`, `staleState`.

### `state` – complete table state

Sent to all clients after every change. The most important fields of `payload`:

| Field | Meaning |
|---|---|
| `phase` | `lobby`, `betting`, `showdown`, `handComplete`, `finished` |
| `street` | `preflop`, `flop`, `turn`, `river` – last street reached |
| `seats[]` | in table order: `id`, `name`, `stack`, `roundBet`, `handBet`, `folded`, `allIn`, `acted`, `mayRaise`, `stackAtHandStart`, `eliminatedRank` (absent while still playing) |
| `buttonIndex` | index of the dealer in `seats` |
| `toActIndex` | index of the player to act (absent when nobody is to act) |
| `currentBet`, `lastRaiseSize` | highest bet of the round; minimum raise = `currentBet + lastRaiseSize` |
| `pots[]` | showdown only: `amount`, `eligible` (player IDs) |
| `clock` | `levelIndex`, `levelEndsAt` (date) or `pausedRemaining` (seconds) |
| `config` | `startingStack`, `levels[]` with `smallBlind`, `bigBlind`, `duration` |
| `version` | increases with every change; send it back as `stateVersion` in `command` |
| `hostID`, `handNumber` | |

Clients only display what the last `state` says and never change it themselves.

### `error`

```json
{"id":"…","payload":"versionMismatch","type":"error","v":1}
```

For errors outside a command. `payload` is a code; the app translates it into text.

| Code | Meaning | Connection |
|---|---|---|
| `versionMismatch` | `hello.protocolVersion` or `v` does not match | closed |
| `tableFull` | already 10 players | closed |
| `gameInProgress` | tournament running, new players can no longer join (reconnecting with a token still works) | closed |
| `helloRequired` | `command` before `hello` | stays open |
| `malformed` | message could not be read | stays open |

## Flow

```text
Client                          Host
  | -- TLS-PSK handshake ------> |
  | -- hello ------------------> |
  | <------------------ welcome  |
  | <-------------------- state  |
  | -- command ----------------> |
  | <---------------------- ack  |
  | <-------------------- state  |   (to everyone)
```

## Versions

If the format changes incompatibly, `v` increases. A host answers a `hello` with a different `protocolVersion` with an `error`.
